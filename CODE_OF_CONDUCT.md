# Código de conduta

Este projeto é um espaço acolhedor para qualquer pessoa, independentemente de experiência, identidade ou origem.

**Esperamos:** respeito, paciência com quem está começando, críticas construtivas sobre o código (nunca sobre pessoas) e boa-fé.

**Não aceitamos:** assédio, ofensas, discriminação, exposição de dados de outras pessoas, nem spam ou autopromoção fora de contexto.

Quem descumprir estas regras pode ter comentários removidos ou ser bloqueado do projeto. Para relatar um problema de conduta, use a aba **Security → Report a vulnerability** ou fale com os mantenedores pelo GitHub.

Baseado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
